# 🔧 Mxm Automation Tool

[![Termux](https://img.shields.io/badge/Termux-Android-blue.svg)](https://termux.com)

> **Herramienta todo-en-uno para automatizar tareas en Termux**

## ✨ Características
- 🔍 Escáner de red y puertos
- 💾 Respaldo automático de archivos
- 🧹 Limpieza de caché y archivos temporales
- 📱 Info detallada del dispositivo
- 🐳 Utilidades para contenedores
- 🎨 Interfaz colorida e intuitiva

## 📦 Instalación

```bash
git clone https://github.com/Falconmx1/Mxm-Automation-Tool.git
cd Mxm-Automation-Tool
chmod +x install.sh mxm.sh modules/*.sh
./install.sh
